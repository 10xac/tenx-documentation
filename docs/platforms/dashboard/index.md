# Management Dashboard — User Guide

The Management Dashboard is the administrative control center for the Tenx Platform. It provides program managers and operations staff with comprehensive oversight across all programs, cohorts, and platform services.

## What It Does

The dashboard enables administrators to manage training programs end-to-end —
from setting up new cohorts and configuring services to monitoring ongoing
operations. It serves as the central hub for operational decision-making.

**Key capabilities:**

- Program and cohort management across the full talent lifecycle
- Service monitoring and operational oversight
- Cross-platform reporting that spans Apply, Tenx Learning, and Leap
- Role-based access control for organization staff
- Real-time operational metrics and service health checks
