# **Tenx Analytics & Reporting Manual**

## **1\. Purpose**

Guide **Staff (Analysts, Program Managers)** and **Super Admins** on extracting, interpreting, and acting on Tenx.

---

## **2\. Roles & Data Responsibilities**

| Role | Key Analytics Actions |
| ----- | ----- |
| **Super Admin** | • Enable system‑wide load & cost monitoring • Approve new dashboards & data‑access permissions |
| **Staff – Analyst / Program Manager** | • View and download dashboards, tables, and stats • Configure Nana & Eagle analytics contexts • Generate reports for cohorts, programs, and job placement |
| **Trainee (Viewer)** | • Access personal dashboards (performance, leaderboard, job status) |

---

## **3\. Core Data Sources & Metrics**

| Area | Metrics Available |
| ----- | ----- |
| **Application Entry** | • Submission form stats • CV‑analysis group stats |
| **Learning** | • Leaderboard scores • Weekly performance dashboard (best submissions, engagement, competency radar) |
| **Question Bank** | • Usage & difficulty stats |
| **Monitoring (Eagle)** | • Engagement, Satisfaction, Experience indexes • Weekly improvement/decline trends |
| **Job Placement (Leap)** | • SJS performance insights • Engagement with jobs & application status |
| **System** | • Load monitoring, cost monitoring  |

---

## **4\. Analytics Tools & Dashboards**

### **4.1 Nana as Data Analyst & BI Support **

* **Context Selection**: choose database tables, Tenx components, or dashboards as conversation context.

* **Dynamic Output**: request on‑the‑fly charts, tables, or dashboard pages.

### **4.2 Eagle Insights Dashboard**

* Real‑time cohort engagement, satisfaction, experience.

* Automated alerts for outliers and declines.

### **4.3 Built‑in Dashboards**

| Dashboard | Access | Description |
| ----- | ----- | ----- |
| **Basic Dashboard** | Staff | Overview of submissions, grades, engagement |
| **Weekly Performance** | Trainee & Staff | Best submissions, engagement, competency radar |
| **Job Application Stats** | Staff | Applications per trainee, status breakdown |
| **Question Bank Stats** | Staff | Item usage, accuracy, label distribution |
| **System Load & Cost**  | Super Admin & Staff | Resource utilisation, day/night mode effects |

---

## **5\. Reporting Workflow**

1. **Select Data Source**  
    • Table download, dashboard view, or Nana query.

2. **Extract Data**  
    • Download as CSV / spreadsheet or capture screenshots.

3. **Analyse Trends**  
    • Compare weekly dashboards, Eagle indices, question bank stats.

4. **Generate Insights**  
    • Highlight engagement dips, grade variance, job‑placement gaps.

5. **Share Findings**  
    • Send bulk email summary or attach report to team channels.

6. **Trigger Actions**  
    • Schedule follow‑ups, adjust content, or modify support strategies.

---

## **7\. Data Governance & Access**

| Principle | Practice |
| ----- | ----- |
| **Least Privilege** | Grant dashboard & table access only to relevant roles. |
| **Privacy** | Remove personal identifiers in shared cohort reports. |
| **Retention** | Archive or delete data per trainee requests. |
| **Audit Logs** | Track who downloaded or modified data tables. |
