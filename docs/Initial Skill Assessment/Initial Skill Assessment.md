### **1\. Why take the assessment?**

- **Personalised learning path** – your scores tell Tenx which modules to unlock or recommend.

- **Baseline for progress tracking** – weekly deltas show how fast you’re improving.

- **Better job matching** – Leap links your competency profile to roles that fit your current level (or just above it).

---

### **2\. How the quiz engine works**

| Feature                 | What it means for you                                                                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Adaptive difficulty** | Questions get harder or easier in real time, honing in on your exact skill ceiling.                                                                                            |
| **Modular domains**     | Each cohort’s quiz targets the skills that matter most to that programme (e.g., Python • SQL • Maths • Statistics for Data cohorts; JavaScript • React • CSS for Web cohorts). |
| **Timed & proctored**   | A single 60-minute sitting; pausing is not allowed to keep results fair.                                                                                                       |

---

### **3\. Taking your first (Initial) Assessment**

1. **Open Dashboard → Tasks → Initial Assessment.**

2. Review the _Instruction_ panel

   - Recommended: desktop/laptop, stable internet, pen & paper for rough work.

3. Click **Start Assessment**—the clock starts.

4. Answer all items; you can flag a question and return while time remains.

5. Click **Submit**. Within seconds you’ll see the results screen.

---

### **4\. Reading your results**

The results page displays:

| Element                 | Description                                                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Total Score**         | Composite across all domains, out of 100\.                                                                                                       |
| **Domain panels**       | Expand **Python / SQL / Maths / Statistics** (or your cohort’s set) to see: • Raw score & % • Correct / incorrect count • Time spent per section |
| **Review Answer Sheet** | Opens every question with the correct answer and short explanations.                                                                             |
| **Done** button         | Returns you to Dashboard and triggers your personalised learning recommendations.                                                                |

A green toast—_“Feedback submitted successfully”_—confirms your data is stored and synced to analytics.

---

### **5\. Tips & troubleshooting**

| Issue             | Fix                                                                         |
| ----------------- | --------------------------------------------------------------------------- |
| Quiz won’t load   | Clear cache or switch browsers (Chrome/Edge recommended).                   |
| Timer froze       | Refresh; the server clock retains your remaining time.                      |
| Score feels wrong | If a technical error is obvious, raise a support request with a screenshot. |
