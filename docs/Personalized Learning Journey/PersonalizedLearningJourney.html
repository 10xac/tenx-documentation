Personalized Learning Journey

Empowering each trainee with a tailored experience on Tenx

Tenx adapts to each learner's strengths, progress, and readiness, offering a personalized journey through modules, assignments, and career preparation tools. The personalized learning flow ensures that no two paths are the same — everyone gets what they need, when they need it.

How It Works

1. Learning Path Recommendation

Upon completing skill assessments (CV analysis + quizzes), each trainee receives a personalized recommendation of modules to focus on. This recommendation helps align their current strengths with the technical and professional demands of the job market.

2. Tailored Modules

Each challenge and module (e.g., building a data warehouse or analyzing user data) is tagged with skills gained (e.g., SQL Programming, DevOps, Math & Stats) and made available based on the trainee's learning path.
Trainees can view challenge overviews, join challenges, and access assignments in one place.

3. Assignment Tracking

Every challenge has a breakdown of required submissions — interim reports, GitHub links, final reports — and these are tracked by submission status (e.g., Missing, OnTime) and grading progress (e.g., Not Graded, or a numeric score).

 

4. Progress Tabs: In Progress / To Do / Done

Modules are organized into intuitive tabs:

  • In Progress: Active modules the trainee has joined
  • To Do: Available but not yet started
  • Done: Completed modules with feedback and grades

Data-Driven Personalization

At the heart of the personalized experience are AI-powered tools like:

  • CV Analysis Feedback – detailed insight into the trainee's job readiness
  • Quiz Results – assessment of technical skill gaps
  • Module Performance – feedback on actual assignments and growth trajectory

What Trainees Experience

  • Clear visibility into modules aligned with their profile
  • Auto-tracked progress across all assignments
  • Immediate visual feedback on submission status and grades
  • Seamless transitions from onboarding to challenge engagement
