# Learners

> **Terminology** — *Learners* and *Trainees* refer to the same role on the Tenx platform.
> Public-facing materials use **learners**; the in-product UI uses **trainees**. Treat them as
> interchangeable throughout this documentation.

Learners are at the centre of the Tenx platform. They use it to apply to programs,
go through structured training, complete assessments, build a professional profile,
and prepare for career opportunities — all in one connected experience.

This page is a **complete map** of what a learner can do, organised by lifecycle
stage. Each item links to the step-by-step guide where it is documented.

---

## 1. Getting onto the platform

Before learners can do anything, they need credentials.

| Action | Where it happens | Link |
|---|---|---|
| Receive platform link | Email after enrollment | — |
| Log in | Tenx Learning login screen | [Login](../platforms/tenx-learning/index.md#21-login) |
| Reset a forgotten password | Login screen → *Forget Password* | [Password reset](../platforms/tenx-learning/index.md#22-password-management) |
| First successful login | Lands on the trainee dashboard | [Trainee home](../platforms/tenx-learning/trainee.md#41-home-page) |

**System requirements:** modern browser (Chrome, Firefox, Edge, Safari), stable internet, desktop or laptop. See [System Requirements](../platforms/tenx-learning/index.md#13-system-requirements).

## 2. Daily learning workflow

What a learner typically does in a working day on Tenx Learning.

### 2.1 Track progress from the dashboard

The **Home** page is the personalised entry point. From here a learner can:

- See module distribution (In Progress / Todo / Done) on a donut chart
- Read the agenda for upcoming deadlines and scheduled activities
- Watch performance metrics and weekly progress
- Inspect the competency radar — skills growing across SFIA areas
- Open notifications

→ [Home Page Highlights](../platforms/tenx-learning/trainee.md#411-home-page-highlights)

### 2.2 Work through assigned topics & modules

Topics organise the curriculum; modules are the learning units inside each topic.

| Activity | Section |
|---|---|
| Switch between **In Progress / To do / Done** topic tabs | [4.3.2 View Topics](../platforms/tenx-learning/trainee.md#432-view-topics) |
| Toggle between card and table view | [4.3.2](../platforms/tenx-learning/trainee.md#432-view-topics) |
| Discover topics outside the assigned curriculum | [4.3.4 Explore Topics](../platforms/tenx-learning/trainee.md#434-explore-topics) |
| Read module content | [4.3.5.1 View Module Content](../platforms/tenx-learning/trainee.md#4351-view-module-content) |
| See module assignments | [4.3.5.2 View Module Assignments](../platforms/tenx-learning/trainee.md#4352-view-module-assignments) |

### 2.3 Submit assignments and review feedback

Assignments are the assessment surface for everything a learner does.

| Activity | Section |
|---|---|
| See all assignments across enrolled modules | [4.4 Assignment](../platforms/tenx-learning/trainee.md#44-assignment) |
| Filter by topic, view grading and submission stats | [4.4.2 View All Assignments](../platforms/tenx-learning/trainee.md#442-view-all-assignments) |
| Open an assignment that is **submitted on time** | [4.3.5.4 Assignment Detail — Submitted](../platforms/tenx-learning/trainee.md#4354-assignment-detail-submitted-on-time) |
| Read the rubric scoring (per criterion) | [Rubric Scoring](../platforms/tenx-learning/trainee.md#4354-assignment-detail-submitted-on-time) |
| Read qualitative feedback per criterion | [Feedback Sections](../platforms/tenx-learning/trainee.md#4354-assignment-detail-submitted-on-time) |
| See what happens when **the submission window has closed** | [4.3.5.3 Submission Window Closed](../platforms/tenx-learning/trainee.md#4353-assignment-detail-submission-window-closed) |
| Add private comments back to the tutor | Same panel as above |

### 2.4 Compare with peers on the leaderboard

Healthy competition keeps learners engaged.

- View ranking by topic, current score, cumulative score
- Switch between topics from the dropdown selector

→ [4.2 Leaderboard](../platforms/tenx-learning/trainee.md#42-leaderboard)

### 2.5 Participate in peer grading

Some assessments are graded by other learners. The Peer Grading page lets a learner:

- See **pending** peer-grading tasks that need their evaluation
- Review **completed** peer-grading work
- Open the assignment, score it against the rubric, leave feedback

→ [4.6 Peer Grading](../platforms/tenx-learning/trainee.md#46-peer-grading)

## 3. Building and maintaining a professional profile

The Profile page is more than personal info — it doubles as a structured CV that
the platform can render into resume templates and feed downstream into Leap.

| Profile area | What the learner does | Section |
|---|---|---|
| **Basic Information** | Name, email, role, contacts, address | [Edit Personal Information](../platforms/tenx-learning/trainee.md#edit-personal-information) |
| **Profession Summary** | Short professional bio | [Update Bio](../platforms/tenx-learning/trainee.md#update-bio) |
| **Work Experience** | Roles, employers, dates, descriptions | [Edit Work Experience](../platforms/tenx-learning/trainee.md#edit-work-experience) |
| **Education** | Schools, degrees, scores, courses | [Edit Education](../platforms/tenx-learning/trainee.md#edit-education) |
| **Volunteer Work** | Organizations and positions | [Update Volunteer Work](../platforms/tenx-learning/trainee.md#update-volunteer-work) |
| **Awards** | Recognitions with dates and URLs | [Add / Edit Award](../platforms/tenx-learning/trainee.md#add-edit-award) |
| **Certificates** | Issuer, title, date | [Add Certificate](../platforms/tenx-learning/trainee.md#add-certificate) |
| **Languages** | Fluency levels per language | [Update Languages](../platforms/tenx-learning/trainee.md#update-languages) |
| **References** | Name, email, relationship, phone, remarks | [Add Reference](../platforms/tenx-learning/trainee.md#add-reference) |

### 3.1 Auto-build the profile from LinkedIn or a CV

Learners don't have to fill every section by hand:

- **From LinkedIn URL** — paste the public profile, click *Generate Profile* → [LinkedIn import](../platforms/tenx-learning/trainee.md#454-generate-profile-from-linkedin-or-cv)
- **From an uploaded CV** — drag a file in; the system parses and populates the form → [CV upload](../platforms/tenx-learning/trainee.md#454-generate-profile-from-linkedin-or-cv)

### 3.2 Download the profile as a resume

Once the profile is filled in, the learner can render it as a polished resume in
several visual templates → [Resume Templates](../platforms/tenx-learning/trainee.md#455-resume-templates).

### 3.3 Track competencies and achievements

| Tab | What it shows | Section |
|---|---|---|
| **Competencies** | Skills the learner has gained, mapped to SFIA levels, with approval status and validation requests. Card and table views available. | [4.5.6 Competencies](../platforms/tenx-learning/trainee.md#456-competencies) |
| **Achievements** | Completed modules and earned certificates. Empty state shown until the first module is completed. | [4.5.7 Achievements](../platforms/tenx-learning/trainee.md#457-achievements) |

## 4. After Tenx Learning — career readiness on Leap

When training has produced enough signal (graded assignments, validated competencies,
a polished profile), learners move into **Leap** to act on opportunities.

Typical Leap activities for learners:

- Generate a job-tailored resume from the Tenx Learning profile
- Browse curated career opportunities
- Participate in **interviews** as part of the hiring flow
- Track applications and outcomes

→ [Leap platform](../platforms/leap/index.md)
