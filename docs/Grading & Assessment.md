# **Tenx Grading & Assessment Manual**

## **1\. Purpose**

Provide **Staff (Instructors & Assessors)** and **Super Admins** with a comprehensive yet concise guide for configuring, executing, and refining grading processes within Tenx.

---

## **2\. Roles & Permissions**

| Role | Core Grading Privileges |
| ----- | ----- |
| **Super Admin** | • Enable roadmap features (large‑scale grading, personalised evaluation) • Manage global rubric standards and grading policies |
| **Staff – Assessor / Instructor** | • Generate & customise smart rubrics • Manage assignment submissions & peer grading • Override automated grades when needed • Publish feedback, dashboards, and leaderboards |
| **Trainee** | • Submit or edit work • Receive instant feedback & grades • Grade peers (where enabled) • Review leaderboards and dashboards |

---

## **3\. Assessment Components**

| Component | Current Capability | 2024‑2025 Enhancement |
| ----- | ----- | ----- |
| **Smart Rubric** | Auto‑generate criteria aligned to learning goals | Personalised evaluation mappings per trainee |
| **Smart Grading** | Automated scoring based on rubric | Large‑scale automated grading with differential weighting |
| **Peer Grading** | Enable cross‑review with configured windows | Scalable peer‑grading for large cohorts |
| **Leaderboard** | Ranks performance by score or engagement | Manageable with insight extraction for trends |
| **Feedback Threads** | Staff & trainees discuss results | Integration with automated follow‑ups on low performance |

---

## **4\. End‑to‑End Grading Workflow**

1. **Create / Upload Assignment**  
    • Use *Manage Challenge Document* or *Module* upload.

2. **Generate Smart Rubric**  
    • Run **generate smart rubrics**; adjust weights if needed.

3. **Publish Assignment**  
    • Define deadlines, resubmission allowances, peer‑grading windows.

4. **Submission Phase**  
    • Trainees *Submit/Edit* work; system logs timestamps.

5. **Automated Smart Grading**  
    • Immediate scoring; Staff review exceptions.

6. **Peer Grading (Optional)**  
    • Trainees review assigned peers; Staff monitor consistency.

7. **Feedback Release**  
    • Publish grades & rubric feedback; open discussion threads.

8. **Dashboard & Leaderboard Update**  
    • Weekly refresh of scores, best submissions, competency radar.

9. **Insight Extraction**  
    • Staff analyse trends; trigger manual or automated follow‑ups.

---

## **5\. Nana‑Enabled Grading Support**

* **Tutor Mode**: answer rubric or assignment queries within \< 1 min.

* **Data Analyst Mode**: provide on‑demand charts or dashboard snippets for grading distribution.

* **Knowledge Base Management**: keep challenge‑document context updated for accurate Q\&A.

**Reminder:** Refresh Nana’s context when rubrics or assignments change.

---

## **6\. Monitoring & Quality Assurance**

| Checkpoint | Staff Action |
| ----- | ----- |
| **Grade Variance Review** | Spot high deviation between auto & manual scores; adjust rubric or model. |
| **Peer‑Grading Consistency** | Compare peer scores with Staff scores; intervene if bias detected. |
| **Engagement Correlation** | Use dashboards to correlate engagement metrics with grade trends. |
| **Feedback Latency** | Ensure turnaround times meet program standards; leverage automated grading to reduce delays. |

---

## **7\. Future**

* **Large‑Scale Automated Grading** – optimise engine for high‑volume cohorts.

* **Differential Week Assignment Management** – vary grading load per cohort pace.

* **Personalised Evaluation** – map rubric weightings to individual learning goals.

* **Instant Submission Feedback for Trainees** – visible upon upload completion.

Track these upgrades in quarterly releases and update grading procedures accordingly.
